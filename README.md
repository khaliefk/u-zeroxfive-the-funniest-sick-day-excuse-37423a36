One line that gets you out of work and gets a laugh. Entry for the
[make.fun bounty](https://make.fun/bounty/u-zeroxfive-the-funniest-sick-day-excuse-37423a36).

## The line

> Sorry boss, I bent down to tie my shoes this morning and my back quit on the spot, effective immediately.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when that is set). The line is 105 characters, one line, plain UTF-8.
